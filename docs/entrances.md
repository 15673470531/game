# 第一章怪物登场

已在小游戏本地项目实现，沿用现有 Canvas 画风和敌人模型。

- 枯井：开场先出现刮擦声、井沿爪子与落灰，一只裂壳爬虫爬出；击败后进入石室精英段落。
- 废屋：第一次出怪时木门震动、眼睛亮起、门板倾倒，怪物从门口跑出。以后只有短动作和扬尘。
- 石室：祭坛后方新增有实际碰撞的石室，两侧与后墙阻挡、门口可通行；两只原有精英按原波次与名称登场，保留属性和技能掉落。
- 巨蝎：祭坛符文闪亮，祭坛前地面开裂，巨钳先伸出、碎石弹起，巨蝎身体随后破土。

首见普通怪和精英演出约 2.8 秒，Boss 约 3.6 秒。镜头缓动到出口，边缘压暗，显示短叙述，再回到玩家。演出期间冻结战斗，不计战斗计时；新出场敌人暂不攻击或受伤，演出结束给玩家短暂无敌时间。后续普通怪使用约一秒的短出场，不反复抢镜头。

新增五个短音效：低鸣、刮擦、撞门、石门摩擦、破土，受原有音效开关控制。共约 232 KB。本次没有修改后端，也没有发布线上版本。

## 存档和兼容

出场状态随本机战斗存档保存。演出中切后台、暂停或结束进程后续玩不会重复生成 Boss。原有旧局已经在场的敌人保留位置，不因更新突然移动到出口。序章教学和调试试炼不启用这一套登场流程。

三波总量、精英属性、熟练度奖励和掉落逻辑沿用原有实现。正式章节开场由“直接精英”改为“井口小怪 → 精英”；井口小怪计入原有小怪配额。

## 验证

- 新出场集成测试：实体出口、战斗冻结、攻击保护、暂停恢复、演出中保存恢复、旧存档兼容，以及从第一波完整推进到通关。
- 多次构建地图检查井、石室、裂隙出口碰撞与可用性。
- 原战斗、序章、熟练度、暂停背包、账号、统计及 BGM 测试通过。
- 新音效事件映射、音量及打包 WAV 文件检查通过。
- 四种出场已通过浏览器实际 Canvas 渲染检查；手机微信里的音量、性能和手感仍需重新编译预览确认。
